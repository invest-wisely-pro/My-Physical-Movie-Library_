MY PHYSICAL MOVIE LIBRARY — VERSIONE WEB SU GITHUB PAGES
=========================================================

Perché la versione web
  - Si INSTALLA davvero come app su Android e iPhone (non solo un collegamento).
  - Funziona offline e la fotocamera dal vivo per i codici a barre funziona.
  - Gli aggiornamenti non fanno perdere i dati: l'indirizzo resta sempre lo stesso.
  - La tua collezione resta nel TUO telefono: su GitHub c'è solo l'app, vuota.

1) PUBBLICARLA (una volta sola, dal PC, circa 5 minuti)
  a. Estrai questo ZIP in una cartella sul PC.
  b. Su github.com: pulsante "+" in alto → "New repository".
     Nome: videoteca · Visibilità: Public (GitHub Pages gratis richiede Public) → "Create repository".
  c. Nella pagina del repository: link "uploading an existing file"
     (oppure "Add file" → "Upload files").
     Trascina TUTTO il contenuto della cartella estratta: index.html, sw.js,
     manifest.webmanifest, LEGGIMI.txt e la cartella icons. → "Commit changes".
  d. "Settings" → "Pages" (menu a sinistra) → "Build and deployment":
     Source = "Deploy from a branch", Branch = "main" e cartella "/ (root)" → "Save".
  e. Dopo 1-2 minuti, in alto nella stessa pagina compare l'indirizzo:
     https://TUONOME.github.io/videoteca/

2) INSTALLARLA
  ANDROID (Chrome): apri l'indirizzo → compare "Installa app" (o menu ⋮ → "Installa app").
     Diventa un'app vera: la trovi anche nell'elenco delle app, si apre a schermo intero.
  iPHONE / iPAD (Safari): apri l'indirizzo → Condividi ⬆️ → "Aggiungi alla schermata Home"
     → lascia attivo "Apri come app web" → "Aggiungi".

3) PORTARCI LA TUA COLLEZIONE
  a. Nell'app che usi oggi: ⚙️ Strumenti → 💾 Backup (scarica il file .json).
  b. APRI L'APP INSTALLATA (dall'icona sulla Home, non dal browser): la libreria è vuota
     → "📤 Ripristina un backup" → scegli il file. Fatto.
     Su iPhone è indispensabile farlo dentro l'app installata: ha una memoria separata da Safari.
  c. Consigliato: ⚙️ Strumenti → ⚡ Precarica tutto (con il Wi-Fi).

AGGIORNAMENTO AUTOMATICO DELL'INDICE IMDb (una volta al mese)
  L'app contiene un indice offline di circa 86.000 film distribuiti in Italia, con voti e
  numero di voti IMDb. GitHub può aggiornarlo da solo ogni mese con i dati ufficiali di IMDb.
  a. Carica nel repository anche la cartella "tools" (con aggiorna_indice.py) e il file
     ".github/workflows/aggiorna-indice.yml".
     La cartella .github è "nascosta" su Windows e Mac: se trascinandola non viene caricata,
     creala dal sito: "Add file" → "Create new file" → come nome scrivi
     .github/workflows/aggiorna-indice.yml → incolla il contenuto del file → "Commit changes".
  b. Primo aggiornamento subito: scheda "Actions" (se compare, conferma di voler abilitare i
     workflow) → "Aggiorna indice IMDb" → "Run workflow". Dura circa 10-20 minuti.
  c. Fatto: l'app pubblicata contiene l'indice di oggi. Aprendola, i voti IMDb dei tuoi film
     si aggiornano da soli e in ⚙️ Strumenti → 🩺 Diagnostica vedi la data dell'indice.
     Da lì in poi si aggiorna da solo il 3 di ogni mese.
  Se l'aggiornamento non riesce a pubblicare: Settings → Actions → General →
  "Workflow permissions" → "Read and write permissions" → Save, poi rilancialo.
  Sul PC, per la versione a file singolo: python tools/aggiorna_indice.py My_Physical_Movie_Library.html
  (serve Python; scarica circa 1 GB di dati IMDb).

AGGIORNARLA IN FUTURO
  Repository → "Add file" → "Upload files" → trascina i file nuovi (sostituiscono i vecchi)
  → "Commit changes". Alla prossima apertura con internet l'app si aggiorna da sola.
  I tuoi dati restano dove sono.

RISERVATEZZA DEL SITO
  - Il sito dell'app chiede ai motori di ricerca (Google, Bing…) di NON indicizzarlo, di non
    mostrarne anteprime né copie salvate: chi non conosce l'indirizzo non lo trova cercando.
  - La pagina del repository su github.com invece resta pubblica e GitHub la mostra nelle sue
    ricerche interne. Per renderla poco riconoscibile usa un nome neutro (es. "archivio-personale"
    invece di "videoteca"): l'indirizzo del sito diventa TUONOME.github.io/archivio-personale/.
    Puoi anche togliere README.md dal repository: serve solo come presentazione.
  - Non condividere l'indirizzo pubblicamente (social, forum).

BUONO A SAPERSI
  - Il repository è pubblico: chiunque può vedere il codice dell'app e l'indice offline dei
    film (dati IMDb ad uso personale). La tua collezione invece NON è lì: resta sul telefono.
  - NON caricare mai su GitHub il tuo file di backup .json: lì dentro c'è la tua collezione.
  - Continua a fare un 💾 Backup ogni tanto (te lo ricorda l'app): serve se cambi telefono
    o cancelli i dati del browser.
